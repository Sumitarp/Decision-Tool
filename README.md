# Razor — Decision-Making Tool

A zero-dependency HTML/CSS/JavaScript decision tool built around the 42 decision-making
razors. This tool is built around the idea of Sumit's Simple Digest Article on Decision-Making Razors.

## Guide to Use the Tool

1. Name a real decision.
2. Enter Option A and Option B.
3. The tool surfaces a few potentially relevant razors using transparent keyword matching.
4. Choose one or more razors.
5. Answer guided questions specific to the selected razor.
6. Generate a decision brief and a practical next step.
7. Browse the full 42-razor library.

## Important design choice

The tool does NOT pretend that a formula can objectively select the "correct" life decision.
Its job is to expose assumptions, missing evidence, emotional distortions, reversibility,
opportunity cost, and future consequences so the user can decide more clearly.
